# Fish Shell Configuration

## Overview

Fish is managed declaratively by **home-manager**. The active configuration is
generated from [`home-manager/modules/programs.nix`](../home-manager/modules/programs.nix)
into `~/.config/fish/config.fish` (a symlink to the Nix store).

> **Note:** [`fish/config.fish`](config.fish) in this directory is **legacy** and
> unused — it predates the Nix setup and references removed tools (nvm, bun,
> `/opt/nvim`). Do not edit it; edit `home-manager/modules/programs.nix` instead.

## Configuration Details

### PATH Setup (`shellInit`)
- Local binaries: `~/.local/bin`
- Go: `/usr/local/go/bin` and `~/go/bin`
- Custom scripts: `~/.dotfiles/custom-scripts`

### Development Tools Integration
- **mise**: activated for interactive sessions (`mise activate fish | source`) —
  handles language versions (node, python, ruby, ...)
- **fzf**: key bindings sourced from the vendor path or `~/.fzf/shell/key-bindings.fish`
- **Starship**: prompt initialized via home-manager (`enableFishIntegration`)
- **LunarVim**: venv auto-activated if `$HOME/.venvs/lvim/bin/activate.fish` exists

### Abbreviations
| Abbr | Expands to |
|------|-----------|
| `ll` | `ls -alF` |
| `la` | `ls -A` |
| `l`  | `ls -CF` |

### Special Configurations
- **WSL**: `DONT_PROMPT_WSL_INSTALL=1` to prevent WSL install prompts

## Key Features
- Intelligent autosuggestions
- Syntax highlighting
- Man page completions
- Web-based configuration (`fish_config`)
- Universal variables

## File Location
`~/.config/fish/config.fish` → Nix store (generated by home-manager)

After changing the config, apply with:

```bash
cd ~/.dotfiles
git add -N home-manager/
nix run home-manager/master -- switch --flake ~/.dotfiles/home-manager -b backup
```
